# Motion Studies

Local C# / UIKit ports of the CapWords shared-transition, Alma circular-carousel,
Slack Catch Up and Opal Set Timer Slider examples from the user's
licensed Make It Animated checkout. The explicit brief is the visual authority:
retain the two word illustrations, dotted paper, date/count headers, list/detail
navigation, 550 ms shared spring and 100/200/300 ms detail arrivals.

This is a framework capability study, not a vocabulary service. Camera, offers,
pronunciation and purchases are placeholders in the reference. The port names
that limitation when those controls are pressed. No service or user data is used.

The gallery is an Experience surface: four artifact-led cards make the studies
recognizable and let the user switch without restarting. Preserve CapWords'
identity while giving Alma its reference cream/forest palette, serif headline,
emoji cards, circular positioning, scale and rotation. Auto-advance runs every
2.5 seconds; native finger dragging and velocity-aware snapping are the user's
requested extension. Swiping pauses auto-play. Keep pause, Previous/Next and
Continue accessible as native controls. Nutrition tracking is not connected.

Slack Catch Up is the third study. Preserve the source's plum gradient, dark
channel cards with skeleton message rows, five-card stack, green Read/right and
blue Keep Unread/left feedback, progress rings, top/bottom-dependent tilt,
quarter-screen commit threshold, short-swipe return, vertical release momentum,
Undo, direction-aware remaining counter and completion. Use the native vertical
message scroller alongside horizontal swiping. Slack account data and composing
messages remain disconnected; the reference uses synthetic channels.

Opal is the fourth study: preserve the source demo's black canvas, intentionally
empty middle, bottom timer strip, mint/green Start Timer action and five icon
controls. Compact minus/duration/plus/Block controls expand into a discrete,
immediate-contact slider through duration press-in or three rapid native step
taps. Preserve the shift, delayed track reveal, spring fill, anchored edge stretch
and retained selection. The gallery preview stays black with a deep green footer
and pale mint copy. SF Symbols replace source font icons; the existing static
ambient glow approximates Start Timer, with no separate breathing/shimmer port.
Blocking, sessions, schedules, screen-time data, accounts and tabs disclose demo
scope in a native drawer. This extension is simulator-only; physical touch,
haptics and VoiceOver traversal remain unverified. No private TSX or assets are
copied; reference media and new captures remain ignored local artifacts.
